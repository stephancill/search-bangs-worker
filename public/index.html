search.stupidtech.net

A DuckDuckGo bangs-compatible search redirector with Google as the default engine.

  • ?q=rust async -> Google search
  • ?q=!w rust -> Wikipedia bang
  • ?q=rust ! -> Google first result
  • ?q=! rust -> Google first result
  • ?q=!notreal rust -> Google search for full query

Example: https://search.stupidtech.net/?q=!w+Cloudflare+Workers

Set as Default Search Engine

Use this URL template: https://search.stupidtech.net/?q=%s

  • Chrome / Brave: Settings -> Search engine -> Manage search engines and site search -> Add (under Site search), then set it as default.
  • Firefox: Settings -> Search -> Search Shortcuts -> Add, then use https://search.stupidtech.net/?q=%s in "URL with %s in place of the search term".
  • Safari: Use a Safari extension for custom default search engines.
