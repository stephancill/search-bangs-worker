search.stupidtech.net

A DuckDuckGo bangs-compatible search redirector with Google as the default engine.

  • ?q=rust async -> Google search
  • ?q=!w rust -> Wikipedia bang
  • ?q=rust ! -> Google first result
  • ?q=! rust -> Google first result
  • ?q=!notreal rust -> Google search for full query

Example: https://search.stupidtech.net/?q=!w+Cloudflare+Workers

Benchmark Snapshot

Measured on 2026-04-26 from this deployment environment (20 requests per case).

  • worker_default avg 138ms, p50 94ms, p90 261ms
  • worker_bang avg 241ms, p50 89ms, p90 176ms
  • worker_bang (warm) avg 103ms, p50 88ms, p90 162ms
  • ddg_default avg 1493ms, p50 1434ms, p90 1594ms
  • ddg_bang avg 1114ms, p50 1089ms, p90 1201ms

Note: first worker_bang requests can be slower due to bang index refresh; subsequent requests use cache.
